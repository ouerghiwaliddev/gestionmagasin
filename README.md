# Gestion de magasin

Application de gestion de stock : API **ASP.NET Core (net10.0)** + **EF Core / PostgreSQL** et interface **Angular**.

Tout le code se trouve dans [`net/`](net/README.md) (démarrage, base de données, tests, sécurité).

L'ancienne version Flask/SQLite a été retirée de l'arbre de travail (elle reste dans l'historique git).
Pour reprendre ses données depuis un ancien `inventory.db` : voir « Reprise des données de l'ancienne version » dans
[`net/README.md`](net/README.md).
